Tower Stack Privacy Policy

Effective date: October 3, 2026

Tower Stack ("the game") is a mobile game made by Manestify. This policy explains what happens to your information when you play it.

The short version

The game does not collect, store on a server, sell, or share any personal information. It works fully offline. Everything it saves stays on your device.

What the game stores on your device

  • Settings: sound, music, vibration, and motion preferences.
  • Records: your best floor, best score, and how many runs you have played and won.
  • Tips: which tutorial tips you have already seen.
  • Run logs: a record of each run (the random seed, when you tapped, the floor you reached, the relics you picked, how long the run lasted, the game version, and your device model and memory size). Run logs help us check that the game is fair and well balanced. They do not contain your name, contacts, location, or any account information.

This data is kept in the game's private storage. Uninstalling the game deletes all of it.

Sending run logs

The settings screen has a "Send run logs" button. It only opens your phone's share menu with a file containing your run logs. Nothing is sent unless you choose an app (for example email or a chat app) and send it yourself. If you send it to us, we use it only to improve the game's balance and difficulty, and we delete it on request.

No analytics, ads, or accounts

The game contains no analytics, advertising, tracking, or crash reporting software, and does not ask you to create an account. It does not request access to your contacts, camera, microphone, location, or files. It only uses vibration for game feedback.

If this ever changes (for example if ads are added), this policy will be updated before that version is released, and the effective date above will change.

Test builds

Before release, test versions are sent to invited testers through Firebase App Distribution, a Google service. Google handles the tester invitation and your email address under its own privacy terms. The game itself still collects nothing.

Children

The game does not knowingly collect personal information from anyone, including children.
